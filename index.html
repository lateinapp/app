Allgemein
Julia dicit: Marcus mercatorem bonum est (Ohne AcI)
→ Julia sagt: Marcus ist ein guter Kaufmann

Nebensatz Subjekt (Marcus) → Akkusativ (Marcum)
Nebensatz Prädikat (est) → Infinitiv (esse)

Julia dicit Marcum mercatorem bonum esse (Mit AcI)
→ Julia sagt, dass Marcus ein guter Kaufmann ist
Infinitiv Perfekt im AcI:
Drückt Handlung aus, die zeitlich vor übergeordneter Handlung stattgefunden hat

Präsens → Perfekt/Präteritum
Perfekt → Plusquamperfekt

Julia vocat Marcum abiisse
→ Julia ruft, dass Marcus fort ging/fortgegangen ist

Julia vocavit Marcum abiisse
→ Julia rief, dass Marcus fortgegangen ist
→ ODER: Julia hat gerufen, dass Marcus fortgegangen sei
Infinitiv Futur im AcI:
Drückt Handlung aus, die zeitlich nach übergeordneter Handlung stattfinden wird

Julia putat Marcum se amaturum (esse)
→ Julia glaubt, dass Marcus sie lieben wird

Infinitiv Futur Aktiv im AcI = PFA + esse
(esse kann weggelassen werden, da durch PFA eindeutig)
Passiv im AcI:
Marcus saepe sē a hoste opprimī dicit
→ Marcus sagt, dass er oft von Feinden überfallen wird

sē = Akkusativsubjekt des AcI
a hoste = Der Handelnde steht im Ablativ mit a/ab
opprimī = Infinitiv Präsens Passiv
Bildung des PPP:
PPP des Verbs + Präsensform von esse, z.B.:
Templum ā Rōmānīs aedificātum est
→ Der Tempel ist von den Römern gebaut worden
Templa aedificāta sunt → Die Tempel sind gebaut worden

laudā | re → laudā-t-us -a -um
terrē | re → ❗ terri-t-us -a -um
audī | re → audī-t-us -a -um
Bildung des PFA:
PFA des Verbs + Präsensform von esse, z.B.:
Rōmānī templum oppugnaturi sunt
→ Die Römer werden den Tempel belagern

laudā | re → laudā-t-ūrus -ūra -ūrum
terrē | re → ❗ terri-t-ūrus -ūra -ūrum
audī | re → audī-t-ūrus -ūra -ūrum
Dativus Possessivus Dativ + esse = "hat" statt "ist"
Lucio villa magna est
→ Das große Landhaus ist dem Lucius
→ Lucius hat ein großes Landhaus
Akk. von Städten Romam → nach Rom
(kein "in" für "nach" notwendig)
Unpersönl. Aktiv Tace! Audimur → Man kann uns hören
→ statt: Sei leise! Wir werden gehört
Venī! Vocamur → Man ruft uns
→ statt: Komm! Wir werden gerufen

Nur bei Sätzen ohne konkreten Handelnden!
A marco vocamur → nicht möglich!
→ Wir werden von Marcus gerufen
